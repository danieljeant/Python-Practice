# Quant Tech Stocks Dashboard

A Python-powered web dashboard for a market-facing quant to track technology stocks, monitor risk, and manage client deal flow while keeping desk PnL healthy.

## What this site includes
- Interactive multi-stock performance chart (Plotly).
- Drawdown monitor for selected focus ticker.
- Position/PnL tracking table with long and short exposures.
- Weekly movers analytics panel.
- Client deal pipeline tracker with mandate stage and notional.

## Run
```bash
python app.py
```

Open: `http://localhost:8000`

> The app serves a single-page dashboard and simulates market scenarios deterministically for fast demos.
